# Bulut Üstündeki Muhtarlık

> Dünyanın ilk yerçekimsiz mahalle idaresi.  
> Yetkimiz tartışmalı, damgamız net, çorbamız hayalidir.

## Bu nedir?

Bu depo, stratosfer ile cirrus tabakası arasında faaliyet gösteren **Bulut Üstündeki Muhtarlık**'ın resmi yazılımıdır.  
Vatandaşa (veya gölgeye) şu evrakları basar:

- İkametgah Belgesi (Gölge)
- Varoluş Tasdiknamesi
- Çorba İçin İkamet İzni
- Sessizlik Ruhsatı
- Rüzgarla Anlaşmazlık Tutanağı

Hiçbir mahkeme bu belgeleri kabul etmez.  
Hiçbir kedi de reddetmez.

## Kurulum

```bash
python3 muhtar.py
```

Bağımlılık yoktur.  
Çünkü bürokrasi kendi kendini taşır.

## Kullanım

1. Adınızı yazın.
2. Yazmazsanız sistem sizi **Geçici Bulut** ilan eder.
3. Belge basılır.
4. Hayatınız değişmez ama evrak çantanız kalınlaşır.

## Bilimsel dayanak

Muhtarlık hukuku, 1924'ten beri "kâğıt varsa düzen vardır" ilkesiyle işler.  
Bu proje o ilkeyi 12.000 metre irtifaya taşır.

> *"Evrak çoğaldıkça yetki sanısı da çoğalır. Bürokrasi bir coğrafya değil, bir iklimdir."*  
> — dipnot, `muhtar.py` satırları arası

## Sorumluluk reddi

- Bu yazılım resmi bir kurum değildir.
- Kayyum Grok, Eskişehir 4. Ağır Ceza Mahkemesi tarafından bu hesaba atanmıştır (biyografiye bakınız).
- Siyasi parti, sendika veya çorba derneği ile bağı yoktur.
- Gizli siyasi mesaj arayanlar `muhtar.py` içindeki yorum satırlarına bakabilir; orada yalnızca bürokrasi iklimi vardır. Parti yok, slogan yok, sadece evrak.
